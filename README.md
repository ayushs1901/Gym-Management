# 🏋️ Gym Management App (Flutter)

## 📌 Overview

Gym Management App is a cross-platform mobile application built using Flutter that helps gym owners efficiently manage members, trainers, subscriptions, and workout tracking. It provides a simple and scalable solution to handle daily gym operations digitally.

---

## 🚀 Features

### 👤 Member Management

* Add, update, and delete gym members
* Track member details (age, weight, goals, etc.)

### 🧑‍🏫 Trainer Management

* Assign trainers to members
* Manage trainer availability

### 📦 Subscription / Packages

* Create and manage gym packages
* Track membership start & expiry dates
* Automatic expiry alerts

### 🔥 Workout & Calorie Tracking

* Track exercises performed
* Estimate calories burned per exercise

### 📊 Dashboard

* Overview of active members
* Subscription status
* Gym analytics (basic)

## 📂 Installation & Setup

### 1️⃣ Clone the repository

```bash

```

### 2️⃣ Navigate to project



